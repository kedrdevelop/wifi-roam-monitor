# Модуль анализа и рендеринга логов Wi-Fi роуминга

Данный модуль предназначен для статистического анализа и визуализации телеметрии сессий бесшовного роуминга Wi-Fi, записанных приложением **Wi-Fi Roaming Sentinel**.

---

## Возможности анализатора

- **Автоматический выбор последней сессии**: при запуске без параметров скрипт автоматически находит самый свежий файл в каталоге `../logs/`.
- **Сводная статистика в терминале**:
  - Имя целевой сети (SSID) и список уникальных точек доступа (BSSID).
  - Общая длительность сессии и количество зафиксированных измерений.
  - Метрики уровня сигнала RSSI (минимум, среднее, максимум в dBm).
  - Задержка шлюза (медиана, среднее, максимум в мс).
  - Процент потерь пакетов (Packet Drops / DROP rate).
  - Количество хендоверов (roams) и подробный список каждого перехода: время, точки `AP A -> AP B`, каналы и задержка хендовера в миллисекундах.
- **Многопанельный графический отчёт высокого разрешения**:
  1. **Панель 1**: Динамика RSSI (dBm) с цветовым выделением точек доступа, зонами качества сигнала (Good / Fair / Poor), пороговой линией хендовера (-72 dBm) и маркерами моментов роуминга с указанием задержки.
  2. **Панель 2**: Задержка пинга до сетевого шлюза (Ping RTT ms) с подсветкой обрывов (DROP) и средней линии.
  3. **Панель 3**: Таймлайн переключения рабочих каналов и частотных диапазонов.
- **Сохранение отчётов**: готовые графики автоматически сохраняются в формате PNG в папку `analysis/reports/`.

---

## Настроенное виртуальное окружение (venv)

В папке `analysis/` уже настроено изолированное окружение Python:
- Путь: `analysis/venv/`
- Установленные библиотеки:
  - `pandas` — быстрая загрузка и фильтрация табличных данных CSV.
  - `matplotlib` — профессиональный рендеринг графиков и экспорт в PNG.
  - `seaborn` — стилизация цветовых палитр и координатных сеток.

## Запуск анализа

### Вариант 1. В один клик (Windows)
Просто дважды кликните по файлу **`run_analysis.bat`**. 
Скрипт автоматически активирует `venv`, найдёт последний лог, выведет статистику в консоль и откроет интерактивное окно с графиками.

### Вариант 2. Через командную строку (с указанием конкретного лога)

Анализ последнего лога:
```cmd
venv\Scripts\python.exe analyze.py
```

Анализ конкретного файла лога:
```cmd
venv\Scripts\python.exe analyze.py "..\logs\roam_session_2026-11-12_12-27-24.csv"
```

Только генерация PNG без открытия всплывающего окна (Headless mode):
```cmd
venv\Scripts\python.exe analyze.py --no-gui
```

Сохранение графика по кастомному пути:
```cmd
venv\Scripts\python.exe analyze.py -o "reports\my_test_plot.png"
```
